# Security Policy

Report suspected security issues privately before opening public issues.

This repository contains agent skill instructions and validation scripts. Security
concerns may include unsafe instructions, misleading review guidance, supply-chain
risks in scripts, or references to compromised external resources.

For now, report issues by contacting the maintainer directly or by opening a
minimal public issue that asks for a private contact path without disclosing
details.

Do not include secrets, private code, or exploit details in public reports.
